# Altamash Studio — APK starter

This is a starter Flutter project for an educational app. It is a demo UI and works offline; it does not yet include accounts, online lessons, or a shared database.

## Build an APK using GitHub Actions (no local coding)

1. Download and extract this ZIP.
2. Open your GitHub repository in a browser.
3. Choose **Add file → Upload files** and upload the extracted files/folders to the repository root.
4. Commit the upload to the `main` branch.
5. Open the repository's **Actions** tab and choose **Build Altamash Studio APK**.
6. Tap **Run workflow** if shown, then open the completed run.
7. In **Artifacts**, download `Altamash-Studio-APK`. Extract it to get `app-release.apk`.

If GitHub's mobile page does not show folder uploads, use the browser's desktop-site option or upload files from a computer.
